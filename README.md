# Currency Exchange Rate Service

## О проекте

**Currency Exchange Rate Service** — это легковесный и открытый веб-сервис для конвертации валют, основанный на официальных данных Центрального банка Российской Федерации (ЦБ РФ).

Сервис решает проблему отсутствия инструмента для получения кросс-курсов валют. Существующие решения либо избыточно сложны, либо платны, а бесплатные источники не предоставляют удобных кросс-курсов напрямую.

## Основная идея

Сервис загружает актуальные курсы валют к рублю из открытого XML‑API ЦБ РФ, асинхронно парсит их и предоставляет возможность конвертировать любую сумму из одной валюты в другую через рубль как базовую валюту. Поддерживается более 52 валют.

## Архитектура

Проект построен по принципу **микросервиса** с контейнеризацией (Docker) и включает следующие компоненты:

- **FastAPI** – асинхронный бэкенд на Python. Обеспечивает:
  - парсинг XML‑ленты ЦБ РФ;
  - кэширование курсов на 24 часа (снижение нагрузки на внешний API);
  - REST API для получения курсов, списка валют и исторических данных.
- **SPA (Single Page Application)** – статический фронтенд (HTML, CSS, JavaScript):
  - реализует glassmorphism UI и адаптивный дизайн;
  - мгновенный пересчёт при выборе валют и вводе суммы (без перезагрузки страницы);
  - анимированный фон с частицами.
- **Docker** – контейнеризация всего приложения для простоты развёртывания и масштабирования.

### Практическая значимость

- **Физические лица** – оценка стоимости валют для поездок, покупок за рубежом, инвестиционных решений.
- **Малый бизнес** – оперативный учёт валютных операций без дорогостоящих информационных систем.
